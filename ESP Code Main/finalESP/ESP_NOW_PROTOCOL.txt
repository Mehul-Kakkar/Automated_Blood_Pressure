ESP-NOW v1 wire protocol (compatible with repository espnowTest/finalDisplay sketches)

Frame layout, packed: uint32 magic 0x42505031; uint16 version 1; uint16 sequence; char type[16]; char payload[180]. Main and display use the same fixed 204-byte layout. The display scans 2.4 GHz channels and discovers the controller locally; it does not join a Wi-Fi network or need Internet access. The main controller's shared radio follows its AP channel when Wi-Fi is connected, so display channel scanning keeps the local link working across that channel change.

Types:
- Display -> main: PING with JSON source/protocol_version.
- Main -> display: PONG; MAIN_STATUS with state, uptime_ms, cuff pressure, and `bp_valid`, `sys`, and `dia`. BP values are experimental candidates: systolic pressure is interpolated at the first detected sound onset after three candidates; diastolic is the pressure at the last detected sound onset after a four-second quiet interval. The display labels them as estimates and not clinical readings. Cuff pressure uses the empirical decreasing-pressure calibration directly: `-1.622066 + 0.00001132803915 * centered_counts` mmHg, with centered counts equal to the HX710B library value minus 8,388,608. Centered signed saturation endpoints are never published as valid pressure.
- Display -> main: COMMAND with `{"cmd":"START","request_id":"<uuid>","session_id":"<uuid>"}`; COMMAND with `{"cmd":"STOP"}`; COMMAND with `{"cmd":"STATUS_REQUEST"}`.
- Main -> display: ACK with ack_sequence, result, reason, state. The sequence correlates acknowledgements. START from the display requires a backend-created session_id; absent one, the main rejects it as backend_session_required.

Both endpoints track a 32-packet sequence window and reject duplicates/replays inside that window. The legacy format is retained for compatibility. Discovery currently uses the existing broadcast-peer test approach; it is not encrypted/authenticated and must not be treated as a production security boundary. No GPIO or display-driver assumptions are made by the display sketch.
